# Dashboard guide

Run the ASP.NET Core app and open its root URL. The dashboard is served from `wwwroot/index.html`.

- `wwwroot/index.html` — dashboard structure
- `wwwroot/styles.css` — responsive styling
- `wwwroot/app.js` — API integration, rendering, filtering and form submissions

The UI uses the same-origin API, so it does not need a separate frontend server.
